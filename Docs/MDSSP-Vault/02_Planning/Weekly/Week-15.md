# Week-15 — 비교 및 실패 사례 분석

상태: **계획** · 상위 계획: [[02_Planning/0000_Project-Plan|Project Plan]], [[02_Planning/0001_Roadmap|Roadmap]]

## 목표

기능·형상·해상도 설정에 따른 차이와 실패 조건을 재현 가능한 자료로 정리한다.

## 작업

- 형상 입력을 켠 경우와 끈 경우의 전파·잔류·적층을 비교한다.
- UV seam 연결, 낮은 Simulation 해상도, 불균형한 전파·포화·Decay 문제를 확인한다.
- 결함별 재현 조건, 관찰 결과, 원인 후보와 해결 여부를 기록한다.
- 가능한 경우 기존 baseline 또는 최적화 전 결과와 정량·시각 비교를 수행한다.
- 최종 보고서의 결과·한계·미완료 작업 초안을 작성한다.

## 산출물

- 비교 이미지와 실패 사례 분석표.
- 재현 조건 및 원인 기록.
- 최종 보고서 초안.
