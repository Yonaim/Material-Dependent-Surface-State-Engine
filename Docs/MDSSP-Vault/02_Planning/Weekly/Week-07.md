# Week-07 — Mud 및 중간 Demo

상태: **계획** · 상위 계획: [[02_Planning/0000_Project-Plan|Project Plan]], [[02_Planning/0001_Roadmap|Roadmap]]

## 목표

Mud의 전파·잔류·적층을 Wetness와 결합해 중간 시연 가능한 결과를 만든다.

## 작업

- Mud의 입력, Transport, Decay 및 높은 잔류 특성을 SRProfile로 조정한다.
- `State × accumulationFactor`로 적층량을 계산한다.
- Cavity Fill, Cavity Excess, Surface Following을 적용한다.
- Accumulation Height와 Normal/Geometry 변화가 보이는 방식을 연결한다.
- Wetness와 Mud를 한 Surface State System에서 확인한다.

## 산출물

- 중간 Demo 영상.
- Wetness/Mud 결과 비교와 Accumulation Debug View.
