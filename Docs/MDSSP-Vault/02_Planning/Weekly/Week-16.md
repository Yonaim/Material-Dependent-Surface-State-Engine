# Week-16 — 최종 결과 정리

상태: **계획** · 상위 계획: [[02_Planning/0000_Project-Plan|Project Plan]], [[02_Planning/0001_Roadmap|Roadmap]]

## 목표

구현물과 증거 자료를 정리해 재현 가능한 최종 Repository, 보고서, Demo와 발표 자료를 완성한다.

## 작업

- 빌드·실행 절차와 필요한 Asset / dependency 안내를 정리한다.
- Repository에서 임시 파일, 중복 문서와 사용되지 않는 구현물을 점검한다.
- Demo 영상을 녹화하고 목표 기능과 테스트 조건을 설명한다.
- 설계, 구현 구조, 검증 방법, 성능 실험, 한계와 미완료 항목을 최종 보고서에 정리한다.
- 발표 자료와 그림·측정 결과의 일관성을 확인한다.

## 산출물

- 정리된 GitHub Repository.
- 최종 보고서.
- Demo 영상.
- 발표 자료.

## 완료 기준

다른 사람이 빌드·실행 절차를 따라 주요 Demo를 재현할 수 있고, 결과와 한계가 보고서·발표 자료에 일치하게 기록되어야 한다.
