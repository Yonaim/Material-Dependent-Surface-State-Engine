## 2. 연구 요지와 요약

처음 읽는 사람도 이해할 수 있도록 쉬운 말로 짧게 작성한다. 수식·약어를 설명 없이 나열하지 않고 필요한 전문 용어는 처음 사용할 때 뜻을 풀어 쓴다.

- 어떤 문제를 해결하려는 연구인가?
- 무엇을 어떻게 바꿔서 문제를 해결하는가?
- 얻은 결과와 프로젝트에서 참고할 핵심은 무엇인가?

작은 칸, 물질의 이동, 입력과 결과 등 해당 연구에 맞는 예시를 사용할 수 있다. 설명용 비유·예시와 연구에서 실제 검증한 결과를 구분한다. 자세한 가정·수식·증명·실험은 다음 절에 둔다.

## 3. 연구 상세 내용

### 3.1 연구 대상과 가정

어떤 현상·데이터·모델을 다루는지, 초기조건과 경계조건 등 결과가 성립하는 전제를 설명한다.

### 3.2 핵심 원리와 처리 순서

핵심 아이디어가 왜 문제를 해결하는지 설명한다. 입력부터 결과까지 단계별로 풀어 쓰고, 관계나 흐름은 Mermaid·그림·작은 예시로 나타낸다.

### 3.3 수식·알고리즘과 변수

핵심 식과 계산 방법을 설명한다. 각 변수의 의미·단위·평가 시점을 먼저 정의하고, 식이 실제로 어떤 연산을 하는지 쉬운 말로 연결한다. 연구의 기호와 프로젝트의 동명 기호가 다르면 구분한다. 해당 항목이 없는 연구라면 생략할 수 있다.

### 3.4 확인한 결과와 근거

무엇을 수학적으로 증명했는지, 무엇을 실험으로 확인했는지 구분한다. 조건·비교 대상·측정값과 출처의 절·페이지를 기록한다. 읽지 않은 증명이나 실험은 미확인으로 표시한다.

### 3.5 계산 비용과 한계

필요한 저장 데이터·반복 계산·시간 간격 조건 등 적용 비용과 한계를 정리한다. 안정성, 정확성, 보존 및 성능을 서로 같은 보장으로 취급하지 않는다.

자세한 설명에도 출처를 연결한다. 독자적인 설명용 예시에는 연구의 실험 결과가 아니라는 점을 명시한다.
