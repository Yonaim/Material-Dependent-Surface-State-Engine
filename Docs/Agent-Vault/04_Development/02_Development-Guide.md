# Development 문서의 역할

이 폴더는 **현재 진행 중인 구현 작업**을 다룬다. [[02_Architecture/03_System-Map|Architecture]]는 현행 구현의 구조와 계약을 설명하고, Development는 아직 끝나지 않은 변경 범위와 현재 선택을 기록한다. 완료된 검증·성능 실험은 [[05_Experiments/03_Experiments-Guide|Experiments]]에 둔다.

| 문서 | 들어갈 내용 |
|---|---|
| [[04_Development/00_Current-Work|Current Work]] | 진행 중인 구현, 다음 변경, 남은 통합 작업 |
| [[03_Decisions/01_Current-Decision-Summary|Current Choices]] | 현재 구현에서 유지하는 선택과 변경 시 재검토할 이유 |

구현이 끝나고 검증이 완료되면 확정된 데이터·수식·지원 경계는 Architecture의 해당 Contract로 옮긴다. 완료 증거와 측정 해석은 Experiments에 기록하고, Current Work에서는 끝난 항목을 정리한다.
