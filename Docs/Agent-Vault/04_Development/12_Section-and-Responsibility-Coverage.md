# Universal 5.5 — 프로젝트 전체 적용 대조표

2026-11-09 Source/Shaders/Scripts/Tests 및 루트 실행 도구 전수 검토. 외부 ThirdParty·생성 Build·중첩 Universal 볼트·자산 데이터는 제외했다. 파일 크기는 검토 보조 신호이며 분리 강제 기준이 아니다. `유지`는 작은 파일만의 면제가 아니라 기존 함수/클래스/모듈 경계와 수명/ABI를 검토한 판단이다. C/JS/TS 구현 파일은 이 범위에 없다. CMakeLists.txt와 CMake/ShaderManifest.cmake는 빌드/variant 등록 계약으로 별도 검토했으며, 현 project/target 구성 및 manifest 모듈 경계가 있어 변경하지 않았다. Config/Assets/Performance-Data의 JSON/mesh/로그는 구현 코드가 아닌 입력·기록 데이터다. PowerShell의 변경은 주석뿐이며 native runtime이 없어 실제 실행은 검증하지 않았다.

각 파일의 두 단계 판단과 근거를 남긴다. 이전 FDebugUI Profiling·C++/GLSL helper 추출을 포함한 현재 상태에 대해 이번 추가 작업을 구분한다. 상세 검증 원문은 [실행 기록](../../../Build/Validation/20261109-230833-vault55-project-wide/summary.md)을 따른다.
