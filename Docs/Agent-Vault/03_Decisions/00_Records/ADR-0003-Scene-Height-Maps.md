# ADR-0003 · 씬에서 Height Map을 직접 지정

- 상태 · Accepted
- 날짜 · 2026-11-26

## 맥락과 선택

수송과 렌더링은 같은 스칼라 바닥 높이장을 읽는다. 파일 종류를 늘리면 높이 복원과 형상별 월류를 매번 검증해야 한다. 기존 카탈로그는 새 형상마다 OBJ와 세 가지 맵을 요구했다. 일반 씬은 높이 맵 한 장과 미터 범위가 있으면 홈의 저장량과 월류를 계산할 수 있다.

## 결정

외부 시뮬레이션 형상은 `.Scene.heightMap`에서 PNG의 경로, `heightRangeM`, 선택적인 `heightOffsetM`으로 지정한다. 한 씬에 높이 맵 하나를 연결한다. 단일 포켓, 쌍둥이 홈, 계단형 수로는 각각 자기 맵을 가리키는 씬으로 구성한다.

노멀 맵은 재질 외관에 쓸 수 있고, OBJ·노멀·signed displacement에서 높이장을 만드는 기존 연구 검사는 보존한다. 곡면의 여러 UV 차트와 seam 수송은 별도로 검토할 수 있다.

## 검증

같은 맵으로 이관 전후 형상 샘플, 수위, 저장량과 월류 시각을 비교한다. 벽돌 용암은 기존 바닥을 16비트 PNG로 옮겼으므로 기본 격자의 높이 재현 오차와 수송을 따로 확인한다.
