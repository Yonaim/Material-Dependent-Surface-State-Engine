# ADR-0002 · 표면 접촉, 퇴적 형상과 수송 시간 간격

- 상태 · Accepted
- 날짜 · 2026-11-25

표면 접촉에 저장 영역 전체를 쓰면 같은 물 질량이 좁은 홈에 모여 있어도 평평한 물막처럼 반응한다. 접촉을 형상 샘플로 계산하면 저장 해상도를 높이지 않고도 차이를 넣을 수 있다. 표본마다 별도의 물 질량을 유지하는 대안은 상태와 수송 경계 수를 늘린다. 현재 구현은 영역당 수위로 물이 닿은 부분을 복원한다.

진흙의 두 성분은 같은 유속을 공유한다. 총질량과 혼합수를 함께 저장하면 수송 장부를 유지하면서 건조와 재습윤에 따라 이동성을 조절할 수 있다. 두 성분이 따로 흐르는 모델이나 조성에 따른 부피 수축이 필요한 장면에서는 모델을 재검토한다.

기존 수송 연결에서 턱의 높이만 갱신한다. 아래층의 퇴적과 제거로 물길이 바뀌어도 저장 영역을 다시 만들 필요가 없다. 한 영역 내부에 새 둑이 생겨 물을 분리해야 할 때는 물질을 보존적으로 재배분하는 규칙이 필요하다.

수송 시간 간격을 바꿀 때 급수량과 국소 반응의 횟수를 일정하게 유지한다. 표시 측에서는 최종 수면과 같은 구간에 기록된 월류를 사용한다. 원시 수심과 표시 수심을 각각 볼 수 있어 수치 수송과 화면 보간의 차이를 진단할 수 있다.
