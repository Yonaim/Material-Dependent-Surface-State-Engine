# Doxygen — C/C++ API 문서화

> Doxygen은 별도의 프로그래밍 언어가 아닌 **C/C++ API 문서화 도구**이다. 코드가 설명하는 What보다 **호출 계약과 Why**를 우선 문서화한다. 일반 코드 주석 규칙은 [`Source Comments`](01_Source-Comments.md)에 둔다.

## 00. 언어 및 적용 범위

- **C/C++ API의 Doxygen 설명 문장은 한국어로 작성한다.** `@brief`, `@param`, `@return`, `@pre`, `@post`, `@warning` 등의 설명과 파일 개요에도 적용한다.
- 태그 이름, 함수·타입·매개변수 식별자, 코드, 표준 API 명칭은 원형을 유지한다. 번역 때문에 식별자나 호출 계약을 바꾸지 않는다.
- 외부 라이브러리의 원본 문서와 자동 생성 코드에는 임의로 언어 규칙을 적용하지 않는다. 프로젝트의 공개 API에 대한 예외가 필요하면 Project Brief 또는 Constraints에 명시한다.
- 한국어 주석을 기록하는 소스 파일은 UTF-8 인코딩을 사용한다. Doxyfile의 `OUTPUT_LANGUAGE = Korean`은 생성 HTML의 인터페이스 언어를 바꾸는 **별도 선택사항**이며, 주석을 한국어로 작성하는 규칙과 구분한다.


- **프로젝트가 직접 관리하는 C/C++ 소스 및 헤더 파일의 최상단에는 `@file` + `@brief`를 필수로 작성한다.** 파일명과 역할을 한국어로 간결하게 적는다. 자동 생성·외부 코드와 바이트 보존이 필요한 파일 등 예외는 [Source Comments](01_Source-Comments.md)를 따른다.
- 공개 API, 비자명한 전제조건·후조건, 소유권·수명, 예외·오류, 단위·범위, 스레드 경계, 상태 전이와 부작용을 우선 문서화한다.
- **파일 헤더의 필수 Doxygen과 개별 함수·타입의 선택적 Doxygen을 구분한다.** 이름과 타입만으로 명확한 getter에 무의미한 `@brief`를 반복하지 않는다.

## 01. 예시

```cpp
/**
 * @file FrameCoordinator.h
 * @brief 한 프레임의 입력 처리, 시뮬레이션, 렌더링 단계를 조율한다.
 */

/**
 * @brief 시뮬레이션을 한 논리적 단계만큼 진행한다.
 * @param DeltaTime 시뮬레이션 간격(초). 0 이상이어야 한다.
 * @pre 시뮬레이션 초기화가 완료되어 있어야 한다.
 * @post 정상 반환 시 외부에서 관찰 가능한 상태가 갱신된다.
 * @warning 시뮬레이션 스레드에서만 호출해야 한다.
 */
void AdvanceSimulation(float DeltaTime);
```

- `@param`, `@return`, `@throws`, `@pre`, `@post`, `@warning`, `@note`, `@see`를 필요한 경우에만 사용한다.
- 선언과 정의에 같은 API 설명을 중복하지 않는다. 공개 API 문서는 가능하면 헤더 선언에 둔다.
- 내부 helper는 필요한 비자명한 부분만 주석으로 설명한다.
- 디버그·시각화 알고리즘 설명과 설계 선택 이유는 필요한 경우 Architecture·ADR로 연결한다.

## 02. 서식 및 생성 설정

- 자연어 설명은 간결한 한국어 평서문으로 쓴다. 함수 이름만 다시 말하는 주석을 추가하지 않는다.
- 단위·범위·소유권·오류 코드는 모호한 표현 대신 확인 가능한 조건으로 적는다.
- 문서 생성 과정에서 한글이 깨지지 않는지 확인하고, 필요하면 Doxyfile의 `INPUT_ENCODING = UTF-8`을 점검한다.
- `OUTPUT_LANGUAGE = Korean`을 선택하더라도 사용자 정의 API 설명 문장은 소스의 주석을 그대로 반영하므로 별도로 한국어로 작성해야 한다.

## 03. 동기화 및 검증

- API·예외·오류·단위·소유권·수명 변경 시 주석과 Contract 문서를 **같은 작업에서** 갱신한다.
- 원본에서 확인하지 않은 보장(예: thread-safe)을 주석에 추가하지 않는다.
- Doxyfile 위치: `{{DOXYFILE_PATH}}`; 대상 범위: `{{DOXYGEN_SCOPE}}` (프로젝트 초기화 시 설정)
