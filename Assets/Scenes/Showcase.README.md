# Showcase scenes

- `Lion Head.Scene`: water wets the carved lion and accumulates inside the
  recessed stone bowl. The lion and basin are separate simulation objects, and
  the animation deposits water on each object independently.
- `Marble Bust 01.Scene`: mud covers the lower sculpture while water spreads across
  the face. Angular stone fragments around its base give the weathered scan a
  ruined setting; the source bust itself is not fractured.
- `Rock 07.Scene`: the dry source rock is visible first. Localized lava and heat
  start after 2.5 seconds and spread across the rock.

All three animations start when the scene is loaded and can be replayed from the
Animation panel. The Scene panel contains direct buttons for each scene.
