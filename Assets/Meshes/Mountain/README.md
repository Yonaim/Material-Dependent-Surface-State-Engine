This model is included as a test asset. The source page lists 3DS, OBJ, and Blender formats and states that the model has no textures or materials; the downloaded archive also contains a JPG image and an MTL file. Check the source page's license terms before using this asset beyond personal testing.

## Files

- `Mountain.obj` and `Mountain.mtl`: Wavefront mesh and material description
- `Mountain.3ds`: 3DS mesh
- `Mountain.blend`: Blender project
- `Mountain.blend1`: Blender backup file included in the download
- `MountainGround.jpg`: image included in the download

The OBJ references the included JPG through a relative MTL path so the texture resolves from this folder.
