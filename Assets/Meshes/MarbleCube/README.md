# MarbleCube

BrickCube와 같은 형상·UV·여섯 Surface를 사용한다. MTL과 Base Color만 대리석으로 바꾸고 Normal Map은 연결하지 않는다.

- 텍스처: [ambientCG Marble001](https://ambientcg.com/view?id=Marble001)
- 원본 파일: `Marble001_1K-PNG_Color.png` (이 폴더에서는 `MarbleCubeAlbedo.png`)
- 다운로드: https://ambientcg.com/get?file=Marble001_1K-PNG.zip
- 라이선스: [CC0 1.0 Universal](https://docs.ambientcg.com/license/)
- 취득일: 2026-09-28

Normal·Displacement·Roughness 텍스처는 포함하지 않는다. 현재 렌더러의 Base Color 경로를 사용하며 대리석 광택 구현을 의미하지 않는다.
