## 실제로 확인한 것

- **F의 T0/T1 재현.** 제공된 매니페스트 25개를 검증했다. T0 64조건·1,024행, T1 6조건·54행을 재현했고 정수 작업량과 통과 판정이 일치했다. 저장 NPZ 최대 절대 차이는 \(1.96\times10^{-14}\)였다. T1은 내부 수송 및 주입 비교였고 저장 사례의 최종 유출은 모두 0이었다.
- **F의 새 비교.** 1D cubic 수송에 수동 contact 상태, pulse 구간, 양방향 면 유량을 포함했다. 218설정·654회에서 실측 상대오차 \(10^{-3}\)과 50 ms의 CPU 기준을 5/5가 만족했다. 물·흔적·장부 상한까지 요구하면 2/5였다. 더 넓은 CPU 예산 200 ms를 둔 \(10^{-5}\) 잔차 상한 기준은 5/5였다. \(T=256\)의 19.41 ms 실측 적분과 89.40 ms 상한 포함 실행은 다른 판정 기준으로 잰 값이다.
- **G의 연결 검증.** 118설정·590회에서 전체 DOP853 \(rtol=10^{-3}\)이 3/3 온라인 비교 기준을 충족했다. 최대 정규화 오차 \(5.51\times10^{-6}\), 관측 p95 0.87–1.57 ms, 복귀 중앙값 0.53–0.55 ms였다. 실제 96셀 장기 기준 누적 경계 전달은 두 방향에서 1.3754와 1.6114였다. 상한을 매 관측에서 계산한 가장 빠른 설정의 p95는 2.25–3.77 ms로 실험용 2 ms 기준을 3/3에서 넘겼다. 이 모든 수치는 CPU 1D 이산 모델에서 얻었다.
- **반례.** 양수성과 질량 보존만으로 \(R\tau\)와 \(L_gR\tau^2/2\)가 성립하지 않는다. 증명에는 자율 비팽창 수송, 동일 초기 상태, 고정 물 경로 및 Lipschitz 접촉 생성 등의 조건이 필요했다. 물 이동 계수를 동결하면 새로 젖는 셀에서 하류 전달을 놓친다. 양 끝이 건조해도 중간 Wet/Dry와 흔적이 생길 수 있다. 같은 최종 물과 경계 총량도 전달 시각이 다르면 흔적이 다르다. 서로 다른 두 경계 적분은 질량 오류를 낳는다.
- **휴면과 재생.** G에서 화면 밖 A와 공유 경계를 동시에 정지하면 총 질량은 보존돼도 B 물 오차는 전체 공급량의 0.708까지, B 흔적은 기준 B 흔적의 0.460까지 어긋났다. 전체 체크포인트 재생은 최종 오차를 \(1.38\times10^{-9}\)까지 줄였지만 과거 제출값은 바꾸지 않았다. 이 결과는 화면 표시와 연결된 물리 상태를 분리해서 검증해야 할 이유를 보여 준다.

## 재사용의 경계

F/G의 독립 기준해, 물·흔적·면 유량 오차 기록, 물리 입력 분할, 상태 및 입력 로그, F/G처럼 관측 구간과 복귀를 구분하는 검증 절차는 다른 연구에 재사용할 수 있다. 이는 실제 박막 손가락, 접촉선, 물방울 변형, 물리 흡수 모델의 검증 자료가 아니다. 일반 상태 모델의 제작비 우위도 확인하지 않았다. 엔진 PERF-042에서는 정해진 대칭 확장 과제에서 구조적 확장 부담 우위가 입증되지 않았고, 사람의 제작 시간 비교는 실행되지 않았다. 별도 P1 패키지는 이번 평가에서 재검증하지 않았으므로 근거로 계수하지 않았다.

입력 로그·체크포인트, 적응형 시간 적분, 잔차 기반 상한, 다중률 보존 전달이나 면 사건에 대한 일반적 기여를 주장할 수 없다. 합성 그래프에서 통과한 CPU 숫자, 렌더러 없는 메모리량, \(\tau\) 충분조건도 제품 성능·지각 품질·2D 물리·학술 신규성의 증거로 쓰지 않는다.
